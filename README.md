## ✨ Principais Funcionalidades

- **Design Premium & Responsivo**: Tema *dark luxury* com tons âmbar/dourado e tipografia moderna (Outfit e Plus Jakarta Sans).
- **Hero & Prova Social**: Destaque para autoridade de +25 anos e avaliação média de 4,5 estrelas no Google (325+ avaliações).
- **Catálogo de Serviços**: Apresentação visual com ícones dos principais serviços (Lavagem detalhada, Polimento, Vitrificação, Higienização interna, Enceramento e Detalhamento).
- **Galeria Interativa**: Visualizador de imagens em alta definição dos carros atendidos com modal de zoom.
- **Integração com Instagram & Google Maps**: Feed de fotos conectado ao perfil oficial e mapa interativo de localização.
- **Botões de Agendamento Rápido**: Botão flutuante e chamadas para ação estratégicas direcionando direto para o WhatsApp.

## 🚀 Como Executar Localmente

### Pré-requisitos
- Node.js (v18+)
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/Davi159345/roncar-automotive-shine.git

# Acesse o diretório
cd roncar-automotive-shine

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse em seu navegador: `http://localhost:8080/`

### Build para Produção

```bash
npm run build
```
